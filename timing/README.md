# Timing probes

68000 programs that measure the ST's timing from the inside; see `../docs/timing-oracle.md` for how they are built, run
in Hatari and compared. `build.sh` builds `software/scenarios/timing/pNN.st` (not committed) with the tools of
`retroclawd-tools` (`rcasm`, `rcdisk`). The probe table is in the Phase 3 plan.
